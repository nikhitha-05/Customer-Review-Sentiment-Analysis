# Customer Review Sentiment Analysis

## Project Overview
This project focuses on analyzing customer reviews to understand customer opinions and identify positive, negative, and neutral sentiments.

## Objectives
- Analyze customer reviews.
- Clean and preprocess review data.
- Identify customer sentiment.
- Visualize sentiment distribution.
- Generate meaningful business insights.

## Tools and Technologies
- Python 3.13
- Pandas
- NumPy
- Matplotlib
- Seaborn
- WordCloud
- VS Code

## Dataset
Dataset: Dataset-SA.csv

The dataset contains customer product reviews, ratings, prices, summaries, and sentiment labels.

## Project Workflow
1. Dataset Collection
2. Data Loading
3. Data Cleaning
4. Missing Value Handling
5. Sentiment Distribution Analysis
6. Data Visualization
7. Final Insights

## Visualizations
- Sentiment Bar Graph
- Customer Review Word Cloud
- Sentiment Percentage Pie Chart

## Key Findings
- Positive reviews represent the largest sentiment category.
- Negative reviews are fewer than positive reviews.
- Neutral reviews represent the smallest category.
